# WebStart Demo Website #1 — Aurelian Grooming

A premium, responsive salon/barbershop demo designed for the WebStart portfolio.

## Preview locally

Open `index.html` in any browser.

## Before using for a real client

Replace the sample business name, address, phone/WhatsApp number, prices, opening hours, map link, social links, testimonials, and photos. The phone number and reviews are placeholders and must not be represented as real.

## GitHub Pages

Upload the contents of this folder to a GitHub repository, then enable Pages from the repository's main branch and root folder.
